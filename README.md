# software-engineering-git-lab

## Lab Practice

This repository is used for practicing basic software engineering workflow with Git.

### Objective

- Learn how to clone a repository, make a small change, and commit it.
- Practice creating clear documentation updates.

### Tasks

1. Pull the latest changes from the repository.
2. Make a focused update in the codebase (for this exercise, this README update).
3. Commit your change with a meaningful commit message.
4. Push and open/update the pull request.

### Expected Result

- The repository contains a clear description of the lab practice workflow.
- Changes are small, reviewable, and committed with meaningful history.
